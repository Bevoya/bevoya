# Bevoya

> **Your life, moving forward.**

Bevoya is a privacy-first personal growth and life-management platform. It helps people turn long-term goals into daily actions, learn more effectively, reflect honestly, understand their habits, and make better decisions over time.

Bevoya is not just a to-do app, habit tracker, journaling app, or AI chatbot. It combines goals, roadmaps, daily planning, focus sessions, learning evidence, reflection, productivity insights, and an AI coach into one calm, practical system.

---

## Why Bevoya exists

Many people consume courses, save motivational content, set goals, and plan their days — but still struggle to see real progress.

Common problems Bevoya addresses:

- Goals feel too big and unclear.
- Daily actions are not connected to long-term direction.
- Learning is passive and hard to measure.
- People watch tutorials but do not build or practice enough.
- Productivity tools track tasks but do not understand skills, evidence, or growth.
- Journals capture feelings but do not turn them into useful next steps.
- Screen time and distractions are visible, but not connected to goals or habits.
- AI tools give generic advice because they do not understand the user’s context.

Bevoya solves this by connecting:

```text
Goals → Roadmaps → Daily actions → Evidence → Reflection → Insight → Better next steps
```

---

## What Bevoya does

Bevoya helps users:

- Define life, career, study, health, creative, or personal goals.
- Break big goals into realistic milestones and skill roadmaps.
- Plan meaningful daily actions.
- Track focused study, work, building, revision, and creative sessions.
- Record learning evidence such as notes, code, projects, quizzes, and reflections.
- Test knowledge with AI-generated quizzes.
- Reflect on what went well, what was difficult, and what to improve.
- Identify repeated distractions, blockers, and weak areas.
- Review weekly and monthly progress.
- Receive practical AI-guided next-step recommendations.
- Connect goals to calendar, tasks, GitHub, learning resources, and screen-time insights.

### The core loop

```text
1. Define what I want
2. Break it into a realistic plan
3. Take action
4. Record what happened
5. Learn from evidence
6. Reflect and adjust
7. Repeat
```

## Who Bevoya is for

Bevoya is designed for people who want consistent, meaningful progress — not just more notifications or productivity pressure.

### Students

Students can use Bevoya to:

- Plan exam revision and assignments.
- Track study sessions and focus.
- Break subjects into topics.
- Generate quizzes from notes and mistakes.
- Identify weak topics.
- Build healthier study routines.
- Receive focused revision recommendations.

Example:

> “Your calculus quiz shows weak understanding of integration. Review today’s mistakes, then redo five similar questions tomorrow.”

### Young professionals

Young professionals can use Bevoya to:

- Build career roadmaps.
- Learn technical and professional skills.
- Track portfolio projects.
- Balance tutorials with practical building.
- Prepare for interviews.
- Track job applications and networking.
- Review weekly career progress.

Example:

> “Your implementation evidence is strong, but interview preparation is behind. Practice two behavioral interview answers tomorrow.”

### Working adults

Working adults can use Bevoya to:

- Manage work and personal priorities.
- Build sustainable routines.
- Track deep-work sessions.
- Protect rest and personal time.
- Reflect on energy, focus, and stress.
- Make progress on long-term personal projects.

### Creators, influencers, and freelancers

Creators can use Bevoya to:

- Plan content ideas and publishing schedules.
- Track content from idea to published post.
- Manage client projects and deadlines.
- Learn new creative or professional skills.
- Review what content performs well.
- Build consistent creative routines.
- Receive practical content and growth suggestions.

Bevoya does not promise followers, virality, or income. It helps creators build sustainable systems and improve based on evidence.

### Parents and older adults

Bevoya can offer a simpler experience with:

- Clear navigation.
- Larger text.
- Gentle reminders.
- Simple daily planning.

## Key features

### Goals and roadmaps

Users can create goals such as:

- Pass final exams.
- Learn Python.
- Become an AI fintech developer.
- Build a portfolio.
- Grow a technical audience.
- Improve fitness.
- Start freelancing.
- Build better routines.

Each goal can include:

- Milestones.
- Required skills.
- Target dates.
- Priority.
- Motivation.
- Linked tasks.
- Evidence.
- Progress tracking.

### Daily planning

Bevoya helps users choose a small number of meaningful actions each day.

Tasks can be categorized as:

- Learn.
- Build.
- Revise.
- Practice.
- Create.
- Work.
- Admin.
- Health.
- Career.
- Personal.

Each task can include:

- Estimated time.
- Priority.
- Due date.
- Linked goal.
- Subtasks.
- Reason it matters.
- Completion status.

### Focus sessions

Users can track real work sessions, including:

- Study.
- Building.
- Revision.
- Practice.
- Reading.
- Creating.
- Work.
- Reflection.

At the end of each session, users can record:

- What they completed.
- What was difficult.
- What evidence they created.
- How focused they were.
- What they should do next.

### Learning evidence

Bevoya distinguishes between:

```text
Watched a tutorial
→ Read documentation
→ Practiced
→ Built something
→ Tested knowledge
→ Applied knowledge in a project
```

This helps users avoid the illusion of progress caused by passive consumption.

### AI coach

The Bevoya AI coach can help users:

- Create a roadmap.
- Plan today.
- Understand why they are stuck.
- Generate quizzes.
- Review their week.
- Identify skill gaps.
- Suggest a next action.
- Recommend learning resources.
- Support career, study, habit, project, and creator goals.

AI recommendations are based on the user’s goals, tasks, sessions, notes, quiz results, reflections, and connected integrations.

### Journal and reflection

Users can write or speak about their day. Bevoya can turn that reflection into structured insight:

- Activities.
- Time spent.
- Wins.
- Blockers.
- Distractions.
- Mood and energy.
- Lessons learned.
- Suggested next action.

Users can edit AI interpretations before saving them.

### Progress and analytics

Bevoya shows meaningful patterns, such as:

- Planned versus completed tasks.
- Focus time.
- Learning-to-building ratio.
- Tutorial-to-implementation ratio.
- Quiz performance.
- Evidence created.
- Skill progress.
- Most productive time.
- Common distractions.
- Repeatedly postponed tasks.
- Weekly and monthly progress.

### Screen-time awareness

Screen-time insights are optional and privacy-first. They help users understand how device usage relates to focus, learning, and goals.

Bevoya does not treat screen time as a moral score. It uses it as context alongside user-recorded sessions, tasks, and reflections.

## Privacy-first by design

Bevoya handles sensitive information, including goals, failures, reflections, mood, study habits, and potentially screen-time data.

Privacy principles:

- Collect only the data needed for a feature.
- Explain why before requesting permission.
- Let users control what the AI can remember.
- Separate private journals from learning notes.
- Allow users to delete individual memories or their entire account.
- Provide data export.
- Never sell personal data.
- Do not train models on private user content without explicit consent.
- Minimize data sent to external AI providers.
- Show the source of AI recommendations.
- Make privacy controls easy to find.

Bevoya is not a medical, legal, financial, or psychological advice service. AI suggestions are guidance, not professional advice.

---

## Product principles

1. **Progress over pressure.**  
   Bevoya encourages consistent action without guilt-based notifications.

2. **Evidence over illusion.**  
   Watching a video is not the same as practicing, building, or applying knowledge.

3. **Daily action over vague goals.**  
   Big goals become useful when broken into realistic next steps.

4. **Reflection over blind productivity.**  
   Users should understand not only what they did, but why it mattered.

5. **Privacy by default.**  
   Users control their data, memories, integrations, and AI access.

6. **Human judgment first.**  
   Bevoya supports decisions; it does not make life decisions for people.

## Technology

Bevoya is built as an Android-first mobile SaaS product.

| Layer | Technology |
|---|---|
| Mobile app | React Native + TypeScript |
| Mobile tooling | Expo |
| Navigation | Expo Router or React Navigation |
| State and server data | Zustand or TanStack Query |
| Validation | Zod |
| Core backend | Java 21+ with Spring Boot |
| Authentication | Spring Security or Supabase Auth |
| Database | PostgreSQL |
| Vector search | pgvector |
| AI service | Python with FastAPI |
| AI workflows | LangChain or LangGraph |
| Background jobs | Spring Scheduler initially; queue system later |
| Billing | Google Play Billing |
| Analytics | PostHog or Mixpanel |
| Crash reporting | Firebase Crashlytics or Sentry |
